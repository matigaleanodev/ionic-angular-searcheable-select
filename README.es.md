# Selects Ionic con búsqueda

[English](README.md)

Ejemplo de aprendizaje: Selección simple y múltiple con búsqueda.

Stack: Angular 20 · Ionic.

## Ejemplo centralizado

Este repositorio conserva su código fuente. La copia ejecutable de la colección, con su propio lockfile, configuración de build e instrucciones, está en [Angular Examples](https://github.com/matigaleanodev/angular-examples/tree/main/examples/ionic-angular-searcheable-select).

Para uso local, seguir el README de la colección y su `.nvmrc` (instalar la versión de Node indicada si hace falta):

```sh
git clone https://github.com/matigaleanodev/angular-examples.git
cd angular-examples/examples/ionic-angular-searcheable-select
nvm use
npm ci --ignore-scripts
npm start
```

Los comandos anteriores ejecutan la copia centralizada. Este repositorio original se conserva como referencia de aprendizaje; no es una plantilla de aplicación productiva.
