# Searchable Ionic selects

[Español](README.es.md)

Learning example: Single and multiple selections with search.

Stack: Angular 20 · Ionic.

## Centralized example

The source is preserved in this repository. The runnable collection copy, with its own dependency lockfile, build configuration and instructions, lives in [Angular Examples](https://github.com/matigaleanodev/angular-examples/tree/main/examples/ionic-angular-searcheable-select).

For local use, follow the collection README and its `.nvmrc` (install the indicated Node version if needed):

```sh
git clone https://github.com/matigaleanodev/angular-examples.git
cd angular-examples/examples/ionic-angular-searcheable-select
nvm use
npm ci --ignore-scripts
npm start
```

The commands above run the centralized copy. This original repository remains a learning reference; it is not a production application template.
